# Papiti v0.6.3: Korean-English language curriculum experiment

**Status: opt-in draft; no weights trained or metrics verified yet.**

This is a lightweight ML training approach **inspired by** the 2022 revised
Korean curriculum's deep conceptual learning and the IB MYP's inquiry,
application, and reflection. It is not an official implementation of either
educational program and does not imply a biological fly has taken an IB course.

## Why this exists

The v0.6.2 inquiry experiment reduced complete training-reply reuse on the
previously consulted 94-combination regression test from **77/94 to 41/94**,
but many non-copied outputs were malformed (e.g. invented word fragments).
A lower copy rate is **not** synonymous with better language understanding.

The next controlled hypothesis is **whether training in stages** improves
complete, grammatical Korean and English sentences *without* changing the
network architecture, adding runtime response templates, or banning words.

## Training plan

- **Foundation (epochs 1–6 with --epochs 30):** For existing social
  utterances, optimize only the first clean sentence of each two-line example.
  Do not supervise the newline, follow-up or EOS during this stage. All
  prompts remain semantic packets generated by the existing brain.
- **Application (epochs 7 onward):** Train on the **entire original 456-row
  inquiry corpus** including both sentences and factual content. Existing
  validation patience selects the checkpoint with the lowest validation
  character NLL; do not assume the final epoch is the best.
- **Reflection (after training):** Compare the same frozen 94 regression
  cases and then run **36 entirely untrained style-pair prompts**. Manually
  inspect grammaticality, meaning and factual preservation.

Both training phases use the existing data; staged loss masking is the main
experiment variable. This approach does not claim to teach human moral
reasoning or guarantee natural grammar. The 36 new probes recombine previously
seen sentence halves, so they are compositional tests rather than blind
open-domain dialogue tests.

## Run from the Codespace

\`\`\`bash
git fetch origin experiment/papiti-v063-language-curriculum
git switch -c papiti-v063-training FETCH_HEAD

.venv-train/bin/python -m unittest tests.test_papiti_v0_6_3_curriculum
make papiti-lm-train-v0.6.3-language PAPITI_PYTHON=.venv-train/bin/python

.venv-train/bin/python -m papiti_lm.v0_6_1 eval \
  --checkpoint artifacts/papiti_language_v0_6_3_curriculum.pt \
  --report artifacts/papiti_v0_6_3_eval.json

.venv-train/bin/python scripts/compare_prose_eval.py \
  artifacts/papiti_v0_6_2_inquiry_eval.json \
  artifacts/papiti_v0_6_3_eval.json

make papiti-lm-transfer-v0.6.3 PAPITI_PYTHON=.venv-train/bin/python

.venv-train/bin/python scripts/review_prose_quality.py export \
  artifacts/papiti_v0_6_3_transfer_eval.json \
  artifacts/papiti_v0_6_3_transfer_review.csv
\`\`\`

Complete grammar_ok, meaning_ok and severe_fact_error as 1/0 **after manual
review** of each generated response:

\`\`\`bash
.venv-train/bin/python scripts/review_prose_quality.py score \
  artifacts/papiti_v0_6_3_transfer_review.csv
\`\`\`

The existing script's provisional copy-rate target was designed for the
94-item regression suite. **Do not use its combined "provisional_targets_met"
flag as the promotion criterion on the 36 transfer examples.** In particular,
a 36-item cross-style transfer challenge is designed to avoid exact full
training-reply matches, but that doesn't make its grammar/meaning correct.

## Controls and limitations

- Existing v0.6.2 checkpoint and inquiry v0.6.2 checkpoint remain untouched.
- Existing corpus, train/validation split and **94 frozen test examples** stay
  unchanged; the extra 36 transfer cases are an additional diagnostic report.
- No generated malformed outputs are copied back into training automatically;
  no test response is used for training. Do not tune against the same 94
  examined regression examples and call it a truly blind result.
- The tokenizer is still fit on **training data only**.
- The core MaleCNS brain remains the authority for facts; the Transformer is
  an experimental language realizer only.
- Because stage-one token supervision is different, train NLL across stages is
  **not** directly comparable. Compare final held-out metrics and manually
  assessed text instead.
- A single run with a fixed seed cannot establish robust improvement. Repeat
  with independent seeds and author a separate genuinely new dialogue test
  before claiming a generalization gain or release readiness.
